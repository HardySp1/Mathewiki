# Mathe-Wissensraum (Manim Edition v2)

## Neuerungen in Version 2

1. **Passwort-Tresor für den Admin-Login:** Beim ersten Login hinterlegst du dein GitHub-Token einmalig zusammen mit einem eigenen kurzen Admin-Passwort. Das Token wird lokal mit AES-GCM verschlüsselt gespeichert – ab sofort meldest du dich nur noch mit deinem kurzen Passwort an. Über **Geräte-Sync** kannst du den verschlüsselten Zugang bei Bedarf auf ein Tablet übertragen.
2. **Stabile Kreis-Geometrie auf Ebene 1:** Die vier Hauptgebiete behalten ihre Kreisform auch dann bei, wenn der Beschreibungstext komplett geleert oder bearbeitet wird.
3. **Strikte Ebenen-Fokussierung:** Auf jeder Zoomstufe wird ausschließlich die aktive Ebene samt ihrer nächsttieferen Bausteine eingeblendet (Ebene 1 wird beim Reinzoomen komplett ausgeblendet; die Zuordnung erfolgt klar über die Manim-Farbcodierung).
4. **Geordnete konzentrische Cluster-Anordnung:** Alle Themengebiete und Lernbausteine sind kollisionsfrei und symmetrisch um ihr jeweiliges Zentrum angeordnet.
